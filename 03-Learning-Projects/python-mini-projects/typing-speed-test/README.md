# Typing Speed Test

A command-line application to test and measure your typing speed and accuracy.

\#\# Features

- Random sentence selection for testing
- Measures typing speed in words per minute (WPM)
- Calculates accuracy percentage
- Displays time taken to complete the test

\#\# Requirements

- Python 3.x
- Standard library modules: `time`, `random`

\#\# How to Run

1. Run `python main.py`
2. Read the displayed sentence
3. Press Enter when ready
4. Type the sentence as fast and accurately as possible
5. View your results (time, WPM, accuracy)

\#\# Sample Sentences

- "The quick brown fox jumps over the lazy dog."
- "A journey of a thousand miles begins with a single step."
- "This is the way for us to reference the object of the class."

\#\# How It Works

- Words per minute is calculated based on the number of words in the test sentence divided by time taken (converted to minutes)
- Accuracy is measured by comparing each character typed with the original sentence

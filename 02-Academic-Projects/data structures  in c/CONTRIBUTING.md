# Contributing to Task Tactics

Thank you for your interest in improving this project! Here are a few ways you
can help:

1. Fork the repository and create a feature branch.
2. Make your changes in C over in `src/` or update documentation under `docs/`.
3. Run the program and ensure it compiles cleanly with `-Wall`.
4. Submit a pull request describing your change.

Please keep code style simple (K&R / BSD indent) and avoid external dependencies.

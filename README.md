# All Projects Portfolio

This repository is a curated portfolio of projects created by a B.Tech Computer Science student. It reflects a learning journey from foundational programming and academic coursework to practical web, database, and machine learning work.

## Structure

- 01-Portfolio: resume-ready projects with strong presentation and practical value
- 02-Academic-Projects: college coursework and core CS fundamentals
- 03-Learning-Projects: projects built while learning new technologies
- 04-Experiments: exploratory or prototype-style work
- 05-Archive: older, less polished, or sandbox-style work
- 06-Utilities: helper scripts and supporting files

## Highlights

- Web development and frontend design
- Backend and API-style projects
- Database and SQL work
- Machine learning and data science exploration
- Core programming and data structure practice
